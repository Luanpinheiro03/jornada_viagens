# ✈️ Jornada Viagens

Landing page de um site de viagens desenvolvida com **HTML5 e CSS3**, com foco na criação de um layout responsivo e na adaptação dos elementos para diferentes tamanhos de tela.

## 📌 Sobre o projeto

O **Jornada Viagens** é um projeto desenvolvido para praticar e aprimorar conhecimentos em **HTML e CSS**, utilizando uma abordagem voltada para a construção de interfaces responsivas.

O principal objetivo do projeto é criar uma experiência de navegação consistente em diferentes dispositivos, adaptando o layout entre **mobile, tablet e desktop**.

## 🎯 Objetivos

* Desenvolver uma landing page utilizando HTML5 e CSS3;
* Praticar a utilização de HTML semântico;
* Criar layouts responsivos;
* Adaptar a interface para diferentes tamanhos de tela;
* Trabalhar com **Media Queries**;
* Praticar Flexbox;
* Implementar recursos básicos de SEO;
* Melhorar a acessibilidade e estrutura semântica da página;
* Aprimorar a organização de arquivos e estilos.

## 🛠️ Tecnologias utilizadas

* **HTML5**
* **CSS3**
* **Flexbox**
* **Media Queries**
* **Meta Description**
* **Open Graph (OG)**
* **Git**
* **GitHub**

## 📱 Responsividade

O projeto foi desenvolvido com foco em **design responsivo**, buscando adaptar a estrutura e os elementos da página de acordo com o tamanho da tela.

### 📱 Mobile

Layout otimizado para telas menores, priorizando:

* Organização vertical dos elementos;
* Melhor aproveitamento do espaço disponível;
* Navegação adaptada para dispositivos móveis;
* Imagens e conteúdos ajustados à largura da tela.

### 📲 Tablet

O layout é adaptado para aproveitar melhor o espaço horizontal disponível, reorganizando os elementos e ajustando tamanhos, espaçamentos e imagens.

### 🖥️ Desktop

Em telas maiores, o projeto utiliza o espaço disponível para apresentar os conteúdos de forma mais ampla, mantendo uma estrutura organizada e confortável para navegação.

## 🔎 SEO e compartilhamento

O projeto também conta com algumas práticas básicas de **SEO (Search Engine Optimization)** e otimização das informações apresentadas quando a página é compartilhada em redes sociais.

### Meta Description

Foi utilizada a tag `meta description` para fornecer aos mecanismos de busca uma descrição resumida do conteúdo da página.


A `meta description` ajuda os mecanismos de busca a compreenderem o conteúdo da página e pode ser utilizada como descrição nos resultados de pesquisa.

### Open Graph

Também foram utilizadas **Open Graph Meta Tags (OG)** para definir como as páginas devem ser apresentadas quando compartilhadas em plataformas e redes sociais. Essas configurações permitem criar uma apresentação mais organizada e atrativa quando o site é compartilhado em redes sociais e aplicativos de mensagens que utilizam o protocolo Open Graph.


## 🚀 Como executar

1. Clone este repositório:

```bash
git clone https://github.com/Luanpinheiro03/jornada_viagens.git
```

2. Acesse a pasta do projeto:

```bash
cd jornada_viagens
```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar uma extensão como **Live Server** no Visual Studio Code durante o desenvolvimento.
